# Navis Elevation

Плагин для **Autodesk Navisworks Manage 2021**: показывает отметку (высоту) элемента
модели прямо при наведении курсора в 3D-виде.

## Зачем

В Navisworks нет встроенной функции показа отметки элемента. Когда модель большая
и смотреть её в разрезе с подписями неудобно, приходится либо открывать исходный
файл в Revit, либо гадать по уровням. Плагин снимает эту рутину: навёл курсор —
видишь высоту.

## Возможности

- Отметка точки под курсором в метрах — независимо от того, в каких единицах пришла
  модель: футы, дюймы или миллиметры переводятся автоматически.
- Границы элемента по вертикали (низ и верх) — сразу видно высоту самого элемента.
- Название элемента и имя файла модели-источника.
- Подсветка элемента под курсором.
- Собственная вкладка **Navis Elevation** на ленте Navisworks: кнопка показа отметки,
  кнопка калибровки и кнопка настроек.
- **Калибровка отметки**: если ноль модели не совпадает с проектным, отметки сдвигаются
  на разницу. Выбираете элемент с известной проектной отметкой — плагин считает сдвиг
  сам. Калибровка хранится отдельно для каждой модели и сбрасывается одной кнопкой.
- В подписи видно, что отметка откалибрована, и какое смещение применено.
- Окно настроек: версия плагина и описание работы.
- **Проверка обновлений**: плагин сам спрашивает у GitHub, не вышла ли новая версия,
  и может её скачать и поставить. Обновление применяется после закрытия Navisworks.

> Раздел «Возможности» описывает целевой функционал. Что уже реализовано и проверено —
> в [docs/realized](docs/realized), что в работе — в [docs/in-progress](docs/in-progress),
> что запланировано дальше — в папке [docs/future](docs/future).

## Требования

- Autodesk Navisworks Manage 2021 (64-бит).
- .NET Framework 4.8 — входит в состав Windows, отдельно ставить не нужно.

## Установка

Готовый установщик: скачать `NavisElevation-1.0.0-setup.exe` из
[релизов на GitHub](https://github.com/temapromaster3000/new-navis/releases) и запустить.
Прав администратора не нужно — всё ставится в папку пользователя.

Установщик кладёт плагин в
`%APPDATA%\Autodesk\ApplicationPlugins\NavisElevation.bundle\`:
`PackageContents.xml` плюс `NavisElevation.dll` в `Contents\2021\`.
Бандл, а не просто DLL, потому что Navisworks 2021 читает плагины из папки
`Plugins` внутри своей папки установки, а писать туда можно только с правами
администратора.

**Полностью закрыть Navisworks и запустить заново.** Бандлы читаются только при
старте, поэтому выкладка в уже открытый Navisworks не подхватывается. DLL Navisworks
подгружает сам, копировать их вручную не нужно.

### Установка из исходников

Для разработки: `build-and-deploy.bat` в корне репозитория. Скрипт соберёт плагин,
разложит бандл в `%APPDATA%` и положит туда же программу-обновлятель.

## Использование

1. Открыть модель.
2. Найти вкладку **Navis Elevation** на ленте Navisworks и нажать «Показать отметку».
3. Навести курсор на элемент — в левом верхнем углу вида появится подпись с отметкой,
   а сам элемент подсветится.
4. `Esc`, правая кнопка мыши или повторное нажатие кнопки выключают режим.

> Во встроенной вкладке Add-Ins кнопок плагина нет: весь интерфейс живёт на собственной
> вкладке **Navis Elevation**.

### Калибровка отметки

В API Navisworks нет базовой точки проекта, поэтому «правильность» отметки нельзя
проверить заранее — она сверяется вручную с элементом заведомо известной отметки.
Отметка всегда переводится в метры, независимо от единиц модели:

```
Балка / Beam 250x500
Отметка: +3.000 м
```

Если элемент с заведомо известной проектной отметкой `+12.000` показан как `9.640`,
разница `2.360` — это ноль проекта. Сдвинуть отметки можно кнопкой **«Калибровка»**
на вкладке Navis Elevation:

1. Нажмите «Калибровка» — откроется окно со статусом и двумя действиями.
2. «Установить новую калибровку» — в 3D-виде появится надпись «Выберите точку
   калибровки» и текущая отметка под курсором.
3. Кликните по элементу, проектная отметка которого известна (например, верх
   перекрытия).
4. В окне введите его проектную отметку в метрах — плагин сам посчитает сдвиг и
   применит его ко всем отметкам модели.

После калибровки в подписи появляются строки «Отметка откалибрована» и «Смещение» —
всегда видно, что число сдвинуто. Кнопка «Сбросить калибровку» в том же окне
возвращает отметки к нулю модели.

Калибровка хранится отдельно для каждой модели в
`%APPDATA%\NavisElevation\offsets.ini` и не попадает внутрь файла модели: коллега
откалибрует у себя сам. На рабочих моделях ноль Navisworks совпал с проектным, и
калибровка не требовалась.

### Проверка обновлений

Кнопка «Настройки плагина» на вкладке **Navis Elevation** открывает окно, в котором
есть кнопка «Проверить обновления»:

1. Плагин спрашивает у GitHub, есть ли релиз новее установленной версии. Если нет —
   так и пишет: «У вас установлена последняя версия».
2. Если релиз есть, показываются его примечания и кнопка
   «Скачать и установить vX.Y.Z».
3. После скачивания плагин спрашивает, запускать обновление сейчас. Файлы подменяет
   отдельная программа `NavisElevation.Updater.exe`: сборка плагина в бандле занята,
   пока Navisworks открыт, поэтому подмена возможна только после закрытия программы.

Если обновление скачано, но Navisworks закрыть не удалось, кнопка в окне настроек
останется — нажмите её позже, и обновление применится при следующем выходе из
Navisworks.

Плагин ходит в сеть только по нажатию этой кнопки. Разбор ответа GitHub сделан на
`System.Web.Extensions` из самого .NET Framework: никаких дополнительных библиотек
рядом с плагином не появляется, а такие библиотеки Navisworks может не подхватить.

## Сборка из исходников вручную

```powershell
dotnet build build\NavisElevation.sln -c Debug
```

Если Navisworks установлен не в `C:\Program Files\Autodesk\Navisworks Manage 2021`:

```powershell
dotnet build build\NavisElevation.sln -c Debug -p:NavisworksInstallDir="D:\Autodesk\Navisworks Manage 2021"
```

## Релиз

```powershell
tools\release.bat
```

Скрипт собирает плагин и обновлятель, собирает архив обновления
`NavisElevation-2021.zip`, компилирует установщик `NavisElevation-<версия>-setup.exe`
и публикует всё это на GitHub как релиз. С ключом `-DryRun` скрипт только покажет, что
уйдёт на GitHub, ничего не публикуя.

## Диагностика

Плагин пишет `%LOCALAPPDATA%\NavisElevation\plugin.log` — файл создаётся в момент
загрузки сборки, а не по нажатию кнопки. По нему видно, загрузил ли Navisworks плагин,
нажата ли кнопка и нашёлся ли элемент под курсором.

Отсутствие вкладки **Navis Elevation** означает, что плагин не загрузился: вкладка
создаётся только при успешной загрузке. Присылай лог — по нему причина определяется
однозначно.

Программа-обновлятель пишет свой журнал в `%APPDATA%\NavisElevation\updater-log.txt`:
в нём видно, дождалась ли она закрытия Navisworks и какие файлы подменила.
