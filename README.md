# Navis Elevation

Плагин для **Autodesk Navisworks Manage 2021**: показывает отметку (высоту) элемента
модели прямо при наведении курсора в 3D-виде.

## Зачем

В Navisworks нет встроенной функции показа отметки элемента. Когда модель большая
и смотреть её в разрезе с подписями неудобно, приходится либо открывать исходный
файл в Revit, либо гадать по уровням. Плагин снимает эту рутину: навёл курсор —
видишь высоту.

## Возможности

- Отметка точки под курсором в метрах — независимо от того, в каких единицах пришла
  модель: футы, дюймы или миллиметры переводятся автоматически.
- Границы элемента по вертикали (низ и верх) — сразу видно высоту самого элемента.
- Название элемента и имя файла модели-источника.
- Подсветка элемента под курсором.
- Собственная вкладка **Navis Elevation** на ленте Navisworks: кнопка показа отметки
  и кнопка настроек.
- Окно настроек: версия плагина, калибровка отметки, проверка обновлений.
- Калибровочное смещение отметки, если модель пришла не от проектного нуля.

> Раздел «Возможности» описывает целевой функционал. Что уже реализовано и проверено —
> в [docs/realized/element-elevation-mvp.md](docs/realized/element-elevation-mvp.md),
> что запланировано дальше — в папке [docs/in-progress](docs/in-progress).

## Требования

- Autodesk Navisworks Manage 2021 (64-бит).
- .NET Framework 4.8 — входит в состав Windows, отдельно ставить не нужно.

## Установка

1. Собрать плагин: `build-and-deploy.bat` в корне репозитория.
2. Скрипт разложит бандл в
   `%APPDATA%\Autodesk\ApplicationPlugins\NavisElevation.bundle\`:
   `PackageContents.xml` плюс `NavisElevation.dll` в `Contents\2021\`.
   Бандл, а не просто DLL, потому что Navisworks 2021 читает плагины из папки
   `Plugins` внутри своей папки установки, а писать туда можно только с правами
   администратора.
3. **Полностью закрыть Navisworks и запустить заново.** Бандлы читаются только при
   старте, поэтому выкладка в уже открытый Navisworks не подхватывается.
4. DLL Navisworks подгружает сам, копировать их вручную не нужно.

## Использование

1. Открыть модель.
2. Найти вкладку **Navis Elevation** на ленте Navisworks и нажать «Отметка элемента».
3. Навести курсор на элемент — в левом верхнем углу вида появится подпись с отметкой,
   а сам элемент подсветится.
4. `Esc`, правая кнопка мыши или повторное нажатие кнопки выключают режим.

> Во встроенной вкладке Add-Ins кнопок плагина нет: весь интерфейс живёт на собственной
> вкладке **Navis Elevation**.

### Калибровка отметки

В API Navisworks нет базовой точки проекта, поэтому «правильность» отметки нельзя
проверить заранее — она сверяется вручную с элементом заведомо известной отметки.
Отметка всегда переводится в метры, независимо от единиц модели:

```
Балка / Beam 250x500
Отметка: +3.000 м
```

Если элемент с заведомо известной отметкой `+12.000` показан как `9.640`, разница
`2.360` — это ноль проекта. Впишите его в файл
`%APPDATA%\NavisElevation\settings.txt`:

```
ProjectOffset=2.36
```

Смещение задаётся в метрах и прибавляется после перевода в метры, поэтому в примере
выше после правки появится `+12.000`. На рабочих моделях ноль Navisworks совпал с
проектным, и файл не потребовался; если на другой модели отметка «поедет», создайте его
вручную.

## Сборка из исходников вручную

```powershell
dotnet build build\NavisElevation.sln -c Debug
```

Если Navisworks установлен не в `C:\Program Files\Autodesk\Navisworks Manage 2021`:

```powershell
dotnet build build\NavisElevation.sln -c Debug -p:NavisworksInstallDir="D:\Autodesk\Navisworks Manage 2021"
```

## Диагностика

Плагин пишет `%LOCALAPPDATA%\NavisElevation\plugin.log` — файл создаётся в момент
загрузки сборки, а не по нажатию кнопки. По нему видно, загрузил ли Navisworks плагин,
нажата ли кнопка и нашёлся ли элемент под курсором.

Отсутствие вкладки **Navis Elevation** означает, что плагин не загрузился: вкладка
создаётся только при успешной загрузке. Присылай лог — по нему причина определяется
однозначно.
