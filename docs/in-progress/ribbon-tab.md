# План: собственная вкладка на ленте и иконка кнопки

## Цель

Кнопка «Показать отметку» сейчас живёт во встроенной вкладке **Add-Ins** — это
работает, но на реальной модели, где подключений несколько, её приходится искать.
Планируется своя вкладка **Navis Elevation** с панелью и кнопкой, у которой есть
иконка, чтобы режим включался в одно нажатие сразу с начала ленты.

Отдельно от MVP это не влияет: функциональность отметки уже работает и не должна
регрессировать при переезде кнопки.

## Что уже известно

| Вопрос | Ответ |
|---|---|
| Нужен ли XAML | **Да, обязательно.** `[RibbonLayout]` принимает путь к XAML-ресурсу, а не строку-идентификатор. По документации Autodesk вкладка появляется только вместе с валидным `RibbonLayout`; ссылка на несуществующий ресурс — вкладка молча не появляется, без ошибки |
| Структура разметки | `<RibbonControl>` → `<RibbonTab Id="NavisElevation.Tab">` → `<RibbonPanel x:Uid="…">` → `<RibbonPanelSource>` → `<local:NWRibbonButton Id="NavisElevation.ToggleCommand">` |
| Совпадение идентификаторов | `Id` вкладки в XAML обязан совпадать с `[RibbonTab]`, `Id` кнопки — с `[Command("NavisElevation.ToggleCommand")]`. Расхождение = кнопка не появляется, ошибок нет |
| Какие сборки нужны в XAML | Ссылки на `Roamer` (GUI Navisworks) и `AdWindows` |
| Локализация | Для локализованного Navisworks файл ленты кладут **и** в `en-US`, и в папку языка установки. Без `en-US` плагин молча не загружается |
| Иконка | Либо `CommandAttribute.Icon`, либо `Image` в XAML-разметке. Отдельный PNG как ресурс сборки |
| Встроенная вкладка Add-Ins | `[AddInPlugin(AddInLocation.AddIn)]` работает и останется как запасной путь |

Полный список проверенных членов API — в `docs/realized/element-elevation-mvp.md`,
раздел «Подтверждённые члены API».

## Этапы

- [ ] Файл `NavisElevation.xaml` в `src/NavisElevation.Navis`, вшит в сборку как `Resource`
- [ ] Ссылки на `Roamer` и `AdWindows` в `.csproj`
- [ ] `[RibbonLayout("NavisElevation.xaml")]` и `[RibbonTab("NavisElevation.Tab", …)]` на классе команды
- [ ] Кнопка в разметке с `Id`, совпадающим с `[Command]`
- [ ] PNG-иконка 16×16 или 32×32 как ресурс
- [ ] `CommandAttribute.Icon` либо `Image` в XAML
- [ ] Решение, остаётся ли `[AddInPlugin]` как дубль кнопки во встроенной вкладке

## Риски

| Риск | Признак | Что делать |
|---|---|---|
| Вкладка не появилась | Нет ни вкладки, ни ошибки | Проверять три вещи по порядку: XAML реально вшит как `Resource`; `Id` в разметке совпадают с атрибутами; Navisworks перезапущен после сборки |
| Кнопка есть, вкладки нет | Панель пустая | Тот же список: чаще всего `Id` вкладки в разметке не совпадает с `[RibbonTab]` |
| Молчаливый отказ на нерусском Navisworks | У пользователя плагин есть, у коллеги нет | Положить XAML ещё и в `Contents\2021\en-US\` бандла |
| Иконка не отображается | Пустой квадрат в ленте | Проверить формат PNG и что ресурс вшит; `Icon` у `CommandAttribute` ждёт путь, а не сам файл |

## Контрольный список ручной проверки

Navisworks агент запустить не может — проверка за пользователем.

- [ ] После сборки и перезапуска Navisworks на ленте появилась вкладка **Navis Elevation**
- [ ] В ней панель с кнопкой «Показать отметку»
- [ ] Кнопка выглядит как кнопка: есть иконка, нет пустого квадрата
- [ ] Нажатие по-прежнему включает режим отметки, подпись появляется
- [ ] `Esc` возвращает стандартный инструмент
- [ ] Вкладка Add-Ins не задваивает кнопку, либо задвоение осознанно оставлено
- [ ] Подсказка при наведении на кнопку показывается
