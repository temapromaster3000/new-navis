# План: док-панель с таблицей значений

## Цель

Сейчас значения показываются подписью у курсора, которая живёт ровно столько, сколько
курсор стоит над элементом. Этого мало, когда нужно **сравнить** несколько элементов или
выписать отметки в отчёт. Док-панель — постоянная панель Navisworks сбоку, где видна
таблица: имя элемента, отметка, границы, модель.

Панель не заменяет подпись у курсора, а дополняет её: подпись отвечает на вопрос «что
под курсором», панель — на вопрос «что я только что посмотрел».

## Почему отложено

Панель требует `DockPanePlugin` — заметно больше кода, чем ToolPlugin с оверлеем, и
свою модель состояния: накопление строк, выбор, очистка. Пока не проверено, что сама
отметка вообще работает, вкладываться в интерфейс поверх неё преждевременно.
Сейчас MVP реализован — см. `docs/realized/element-elevation-mvp.md`.

## Что уже известно

| Вопрос | Ответ |
|---|---|
| Можно ли встроить панель в 3D-вид | **Нет.** У `View` нет ни одного метода для показа панели, а `ViewControl` — обычный WinForms-контрол, подвесить его нечем. Собственная панель возможна только как `DockPanePlugin` |
| Как объявить | Атрибут `DockPanePluginAttribute` на классе, панель регистрируется как плагин в том же реестре, что и остальные |
| Чем заполнять | `WinForms` (`System.Windows.Forms`) — сборка уже подключена в `.csproj` |
| Данные | Те же, что использует `ElevationProbeTool`: `PickItemResult.Point.Z`, `BoundingBox()`, `Document.Grids.ActiveSystem.Levels`, `DocumentCatalog.FindOwningModel` |

Подробности про отсутствие `ViewControl` в API — в
`docs/realized/element-elevation-mvp.md`, раздел «Чего в API нет».

## Этапы

- [ ] Класс панели на `DockPanePlugin` с атрибутом локации
- [ ] `WinForms`-форма: таблица (`DataGridView` или `ListView`) с колонками
      «Элемент», «Отметка», «Границы», «Модель»
- [ ] Накопление строк: дописывать при смене элемента под курсором, а не затирать
      предыдущую, как делает подпись
- [ ] Кнопки «Очистить» и «Экспорт в CSV» — насколько нужны, решить на этом шаге
- [ ] Подсветка выбранной строки в 3D-виде и обратный выбор элемента в модели
- [ ] Формат отметки берётся из `ElevationFormatter` — общей логики не дублировать

## Риски

| Риск | Признак | Что делать |
|---|---|---|
| Панель не появляется | Нет панели в списке DockPane | Проверить атрибут локации у класса панели и перезапустить Navisworks |
| Панель есть, таблица пустая | Строки не накапливаются | Панель должна получать данные из того же `Probe()`, что и подпись; накопление вести в панели, а не в инструменте |
| Рост потребления памяти на большой модели | Модель подвисает после часа работы | Ограничить число строк и не хранить ссылки на `ModelItem` дольше необходимого |
| Двойная подсветка элемента | Элемент остаётся синим после снятия выделения | Сбрасывать `ResetTemporaryMaterials` по списку, как уже делает `ElevationProbeTool` |

## Контрольный список ручной проверки

Navisworks агент запустить не может — проверка за пользователем.

- [ ] Панель появляется в списке панелей Navisworks и открывается
- [ ] При наведении на элементы таблица наполняется, а не заменяется одной строкой
- [ ] Отметка в таблице совпадает с подписью у курсора
- [ ] Кнопка «Очистить» работает
- [ ] Вкладка обновляется при открытии другой модели
- [ ] Панель не мешает просмотру: модель подвигается мышью без рывков
- [ ] После закрытия и повторного открытия Navisworks панель поднимается без ошибок
