# План: выбор проектного нуля

> **Статус: отложен.** Признан нужным, но не реализован. Лежит в `future/`, потому что
> на текущих моделях не требуется: ноль Navisworks совпал с проектным, калибровка
> подтверждена сверкой с проектной отметкой.

## Цель

Дать пользователю указать точку, от которой считаются все отметки.

Сейчас плагин считает от нуля Navisworks, и на рабочих моделях это совпадает с
проектным нулём. Но совпадение не гарантировано: федеративная модель собирается из
моделей со своими `Model.Transform`, и общая точка отсчёта может оказаться где угодно.
Пользователю нужна возможность показать плагину, где настоящий ноль.

## Установленные факты об API

Проверено рефлексией по `Autodesk.Navisworks.Api.dll` из установленного Navisworks 2021.

| Факт | Следствие |
|---|---|
| Диалоговых типов в API нет вообще | Свой выбор режима придётся делать без окна либо своим окном на WinForms |
| У `Plugin` есть только `GetString`, `GetStringSafe`, `TryGetString` | Записать настройки средствами Navisworks нельзя, нужен свой файл |
| У `ModelItem` нет `SetNamedData` / `GetNamedData` | Записать ноль внутрь NWF невозможно |
| У `Model` есть `Guid` и `SourceGuid` | Ключ для хранения, переживающий переименование и перемещение файла |
| `Application.Gui.MainWindow` даёт `IWin32Window` | Своё окно можно сделать модальным, оно встанет поверх Navisworks |
| У `ToolPlugin` есть `MouseDown` | Выбор точки кликом реализуем |

## Открытое решение 1: как выбирается режим

Решение не принято. Три варианта:

### Вариант А. Без диалога, клик или Esc

Кнопка включает режим «выбери проектный ноль», в оверлее висит подсказка. Клик — ноль
выбран. Esc — отмена, остаётся отметка модели.

Плюсы: работает сразу, ничего нового в интерфейсе не появляется, подсказка объясняет
оба действия.
Минусы: выбор неочевиден — человек должен догадаться, что Esc означает «оставить как есть».

### Вариант Б. Своё окно на WinForms

Форма с двумя кнопками «Использовать отметку модели» и «Откалибровать», родитель —
`Application.Gui.MainWindow`.

Плюсы: выбор явный, формулировки свои.
Минусы: около 60 строк кода, риск перерисовки — не проверен. Пока окно открыто,
Navisworks может продолжать слать события.

### Вариант В. MessageBox с кнопками Да/Нет

Плюсы: пять строк кода.
Минусы: чужие надписи на кнопках, выглядит как инородное окно.

**Рекомендация: вариант А.** Он ничего не стоит, а выбор всё равно выражается одним
действием — клик или Esc.

## Открытое решение 2: ноль и смещение — одно понятие или два

Решение не принято. Сейчас в плагине есть `ProjectOffset`: отметка считается как
`метры(Z) + ProjectOffset`. Выбор точки даёт другое: `метры(Z − Z_клика)`, то есть в
точке клика получается ноль.

Вариант А. Оставить одно понятие «проектный ноль». `ProjectOffset` убрать как
дублирующий. Правки затронут `ElevationFormatter`, `ProjectSettings`, README и
инструкцию по калибровке.

Вариант Б. Оставить обе настройки. Больше гибкости, но две настройки об одном нуле
запутают и пользователя, и документацию.

## Хранение

Файл `%APPDATA%\NavisElevation\zeros.ini`, секции по `Model.Guid`:

    [7a3f1c2e-...]
    Zero=3.000

При включении режима плагин ищет запись по Guid активной модели и применяет её
автоматически. Записи нет — работает как сейчас.

**Чего хранилище не делает:** ноль не попадает внутрь NWF и не передаётся коллеге. Тот,
кто откроет файл у себя, откалибрует один раз сам.

## Риски

| Риск | Признак | Что делать |
|---|---|---|
| Модель без сохранённого нуля | Отметки как раньше | Это штатный режим: нуль не выбран, работает от нуля Navisworks |
| `Model.Guid` меняется между запусками | Ноль не подхватывается | Проверить; запасной ключ — путь к файлу |
| Клик промахнулся мимо геометрии | Ноль не задался | Сказать об этом в подсказке и не выходить из режима |
| Файл `zeros.ini` удалён | Ноль потерян | Показывать значение в подписи, чтобы его можно было восстановить |
| Слишком много вариантов | Растёт время задачи | Решения принимать по одному, начинать с варианта А: он ничего не стоит |

## Контрольный список ручной проверки

Navisworks агент запустить не может — проверка за пользователем.

- [ ] Кнопка включает режим с подсказкой «кликните по поверхности, Esc — отмена»
- [ ] Клик по полу задаёт ноль, и в этой точке подпись показывает `0.000`
- [ ] Отметки выше точки клика положительные, ниже — отрицательные
- [ ] Esc выходит без последствий, отметки считаются как раньше
- [ ] Ноль сохраняется: закрыть Navisworks, открыть заново, включить режим
- [ ] Ноль применился автоматически, без повторного клика
- [ ] Вторая модель имеет свой ноль и не берёт ноль первой
- [ ] Подсказка пропадает после выбора точки
